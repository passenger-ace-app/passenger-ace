# 디자인 검토

새 디자인을 만들지 않고 시안을 옮겼다. 세 스킬은 웹 기준이라 차량 화면에 맞는 것만 썼다. Pleos 규칙이 먼저다. 실행 파일은 돌리지 않고 문서만 읽었다.

**기기 화면은 아직 못 봤다.** `화면/`의 5장은 Robolectric으로 그린 그림이고 시안과 눈으로 비교했다. 글자 넘침, 터치 크기, 간격은 코드로 쟀다. 측정값과 고친 버그는 `시험-기록.md`.

## anti-slop-web-design

| 규칙 | 결과 | 이유 |
|---|---|---|
| 글꼴 이름을 정하고 짝 짓기, 웹폰트 | 제외 | 시스템 기본 서체를 쓰고 새로 내려받지 않는 조건. 나중에 Pleos의 Asta Sans로 바꾼다 |
| 색을 토큰으로, 강조색 한 곳 | 적용 | `Ui.kt` 상수로 뒀다. 강조색은 추천 동작 버튼에만 쓴다 |
| 그라데이션 금지 | 적용 | 단색 채움만 쓴다 |
| 비대칭 배치 | 제외 | 랜딩용 규칙. 왼쪽 내비, 오른쪽 앱은 Pleos 창 구조로 정해져 있다 |
| 등장 움직임, 스크롤 움직임 | 제외 | 운전 화면에 움직이는 그림을 두지 않는다. 눌림 95%만 쓴다 |
| 실제 이미지 넣기 | 제외 | 그림을 넣지 않는 조건 |

## design-rules-companion

| 규칙 | 결과 | 이유 |
|---|---|---|
| 글자 16px 이상, 14px은 보조만 | 적용, 더 크게 | 차량 기준이 더 높다. 72, 48, 36만 쓴다 |
| 8단위 간격 | 적용 | 시안 값 그대로. 8, 16, 24, 36, 48, 56 |
| 강조색 1곳 | 적용 | 화면마다 추천 동작 하나 |
| 클릭 영역 44px | 적용, 더 크게 | 터치 영역 116 이상, 간격 36 이상. 버튼은 128, 148, 152 |

## impeccable

| 규칙 | 결과 | 이유 |
|---|---|---|
| 여섯 질문 먼저 | 적용 | 제품브리프의 "여섯 질문"으로 답이 있다 |
| 평가자 둘로 평가 | 제외 | 시안을 옮기는 일이고 시안 채점은 이미 끝났다. 측정은 `ScreensTest`로 대신했다 |
| detect, live 등 실행 파일 | 제외 | 이 컴퓨터 규칙으로 금지 |
| "Go all out" 표현 | 제외 | 시안을 옮기는 일이고 운전 중 시선을 끌면 안 된다 |
| 네이티브 관습 우선 | 적용 | 시스템 미디어 줄, 시스템 알림, 미디어 키를 그대로 쓴다 |

## 시안과 달라진 점

| 화면 | 시안 | 동작판 | 이유 |
|---|---|---|---|
| 2 | 노래, 말동무 버튼 | 뺐다 | 이번 범위 밖 |
| 2 | 주차 도우미 "순서를 말해 드려요" | "핸들 상태를 말해 드려요" | 순서 설명을 앱에 넣지 않는 규칙에 맞췄다 |
| 2, 2-2 | 말수 버튼 "말수 보통" | "말수 줄이기" / "말수 되돌리기" | 시안 문구가 바뀌었다. 누르면 일어날 일을 쓴다 |
| 2-2 | "에이스야, 그만해"로 꺼요 | "운전 중에는 미디어 줄이나 운전대 키로 꺼요." | 호출어가 없다. 두 줄로 나눴다 |
| 2, 2-2, 9 | 짧게 5분, 5분과 15분 | 약 N분 | 실제 파일 길이를 쓴다 |
| 2, 2-2 | 왼쪽 "42분 42km" 판 | 뺐다 | 지어낸 값이 실제 앱에 뜨지 않게 |
| 9 | 4줄(해와 바람 포함) | 3줄 | 녹음이 3편이다 |
| 10 | 큰 글자 "자리를 지나서 멈춰요", 1 / 5, 다음과 그만 | "순서 안내는 확인 후 추가", 그만 하나 | 운전 강사 확인 전이라 순서를 넣지 않는다. 눌러도 할 일이 없는 "다음"은 뺐다 |

## 남겨 둔 문구, 판단 필요

- 화면 1의 "말동무도 해 줘요."는 브리프의 고정 문구라 그대로 뒀다. 동작판에는 말동무가 없다.
- 화면 9의 "물어본 말의 답"도 같다.
